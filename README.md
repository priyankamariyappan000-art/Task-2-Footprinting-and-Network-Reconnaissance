# Cybersecurity Practical – Network Reconnaissance and Network Discovery

## Introduction
This project documents my hands-on cybersecurity practical activities using Kali Linux, Windows Command Prompt, and Zenmap.

## Tools Used
- Kali Linux
- WHOIS
- WhatWeb
- Nslookup
- Curl
- Wafw00f
- DNSRecon
- Windows ipconfig
- Zenmap

## Practical Activities
1. Collected domain registration information using WHOIS.
2. Identified website technologies using WhatWeb.
3. Performed DNS lookups using Nslookup.
4. Examined HTTP response headers using Curl.
5. Checked website WAF information using Wafw00f.
6. Performed DNS enumeration using DNSRecon.
7. Checked local network configuration using Windows ipconfig.
8. Performed network discovery using Zenmap Quick Scan.
9. Reviewed the network topology in Zenmap.
